# 本地运维须知

本地工作台只监听回环地址，按单用户进程运行。同一 `PAPER_AUDIT_RUNTIME_DIR` 只能有一个工作台实例；不要直接绑定公网地址。平台账号、权限、对象存储与调度由佰茵云后续接入。

停止服务不会撤销已发出的付费请求。模型超时或用量不明时，账本保留待核对金额且不自动重试；先查服务方账单，再由管理员在服务停止后使用 `tools/reconcile_model_bill.py` 对账。不得通过删除 SQLite 文件“解锁”。

备份与恢复应复制完整 `runtime/`，包含材料、结果、任务索引、复核和费用记录；只复制报告不足以恢复工作状态。任何删除真实科研材料的操作都需明确归属、保留期限和备份策略，本地版不会自动清理用户材料。

完整功能与费用边界见[根 README](../README.md)和[DeepSeek 接入说明](../docs/product/07_DeepSeek接入说明.md)。
