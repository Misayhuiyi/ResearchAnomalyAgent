# 本地独立运行版 Spec V2.3

范围：由本项目开发方交付 Windows 本机单用户工作台。佰茵云身份、租户、对象存储、调度、部署与联调不在本版实现，详见[平台接入清单](../product/09_平台接入清单.md)。历史完整版 V2.0 是长期规划，不等同于此版验收。

核心流程：提交同一论文的材料（上传或用户确认公开候选）→ 文件校验 → PaperConan 真实扫描 + 明示口径的确定性补充规则 → 覆盖状态及证据 → 人工复核 → 可选按线索报价/确认/DeepSeek 解释 → 导出初筛与冻结报告。模型输出永不改变确定性检测和人工状态。任何未读范围和模型失败均须可见。

输入：CSV/TSV/XLSX/XLS/XLSM/XLSB/文字 PDF/DOCX；扫描图片不支持。最多 20 份、单份 20 MB、合计 100 MB 的**上传边界**，不是所有组合的完整计算容量保证。危险文件名、路径穿越、非法扩展名、空文件、重名及超限必须在扫描前拒绝。扫描资源上限为 1 GiB 引擎进程树常驻内存与 180 秒。

输出：检查编号、材料/工作表/数据块/数值统计、覆盖状态、发现类型/优先级/文件/表/行列/关系式/命中数、可追溯原始证据、中文白话说明、人工复核状态；标准化 JSON、原始 PaperConan JSON、初筛 HTML；冻结复核报告的 Word、PDF、Excel、HTML。

模型：官方 API `deepseek-flash`（展示名 DeepSeek-V4.1-Flash），只传单条线索的有限字段和最多 3 组对照或 4 个焦点数值；请求摘要不超过 3000 UTF-8 字节。调用前展示保守费用上限并保存授权，超时不盲目重试，明确 HTTP 429 最多重试一次；无密钥或失败时人工与扫描功能继续可用。解释必须包含发现、理由、可能合理原因、核验步骤和克制摘要，并强制附“统计信号不等于科研不端结论，也不能判断作者意图”的声明。

信任边界：本地 HTTP 只监听回环地址；`runtime/` 保存材料、账本和报告并禁止提交。公开链接只获取经过地址与跳转验证的直连文件，不绕过登录/付费。平台适配不得沿用本地固定身份。

验收证据：后端 174 项、六组浏览器 43 项、新增 AI 浏览器 4 项、公开论文浏览器 5 项通过；真实模型 1 次最小冒烟仅证明连接和账本。20 份近 100 MiB 密集数值材料未通过完整容量测试，列为已知限制而非隐藏通过。详见[测试验收报告](../product/08_测试验收报告.md)。
