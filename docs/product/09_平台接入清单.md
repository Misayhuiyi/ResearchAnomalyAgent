# 佰茵云平台后续接入清单

以下事项**不属于当前本地开发实现**，也未宣称已联调或部署。平台方应提供接口地址、字段、测试租户和验收环境后逐项完成：

1. 平台登录态、用户/租户身份映射、本人材料可见性和角色权限；本地 `LOCAL_ACTOR` 不能在平台环境使用。
2. 上传文件和报告的对象存储、加密、访问鉴权、配额、保留与删除策略；当前 `runtime/` 是本机单用户存储。
3. 后台任务调度、取消/重试语义、进度回调、超时/资源配额及多实例并发控制；当前是本机线程与 SQLite。
4. 平台密钥管理、模型费用归属、计费确认界面、服务方账单对账和异常费用人工处理；不能直接搬运用户本机 DPAPI 配置。
5. 平台应用路由、HTTPS、反向代理、跨域/CSRF、审计及安全扫描。当前 HTTP 服务仅监听本机回环地址，不能直接公网部署。
6. 正式运行包、容器及平台规范验收。现有四组件候选包与静态审计不等于平台发布；Docker 守护进程未在本机完成构建验收。
7. 真实平台测试：至少覆盖两用户隔离、同租户/跨租户拒绝访问、失败恢复、报告下载鉴权、费用上限与并发任务。

对接合同应沿用本地 API 的任务、结果、线索和费用语义，但具体认证头、文件引用、存储 URL 与回调字段需以平台最终接口文档为准。不得用本机演示通过替代平台验收。
