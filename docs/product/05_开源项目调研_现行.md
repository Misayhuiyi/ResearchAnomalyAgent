# 开源项目调研与复用决策

本地版本直接依赖 [PaperConan 0.8.5](https://github.com/zixixr/paperconan)，未复制其源码。它已有科研源数据解析、固定平移/比例、重复和尾数等可复现检测器及证据/覆盖输出，与任务书及 PaperConan 推文强调的“程序找规律、研究人员核对原因”一致。MIT 许可见 [上游 LICENSE](https://github.com/zixixr/paperconan/blob/main/LICENSE)。本项目额外提供上传安全、历史、中文界面、人工复核、报告和有限证据的可选 AI 解释。

| 项目 | 适用点 | 本次决定 |
| --- | --- | --- |
| [PaperConan](https://github.com/zixixr/paperconan) | 科研数据的确定性扫描、证据和覆盖状态 | 固定版本依赖，作为数值事实来源 |
| [statcheck](https://github.com/MicheleNuijten/statcheck) | 已发表论文中的统计检验/P 值一致性 | 留作未来正文专项检查；本期未复制或集成 |
| [SheetProof](https://github.com/Almehmadi-Ai/sheetproof) | 数值来自确定性工具、回答可追溯 | 只借鉴设计原则，未复制代码 |
| [TABARD](https://aclanthology.org/2025.findings-emnlp.1189/) | 表格异常推理评测 | 可用于未来解释质量评估；本期未引入数据集 |

技术边界：PaperConan 命中是可复现的数值关系，不是“不端识别器”。模型只解释单条命中、列举可能合理原因与复核步骤，不重新计算或篡改数值。小样本、派生列、共同对照、单位换算等情况容易产生良性信号，必须回原表检查。
