# 建设蓝图—页面—实现对照（V2.3）

以 [建设蓝图 V2.3](02_论文科研数据异常筛查Agent建设蓝图_V2.3.docx) 和运行页 `mvp-demo/static/index.html` 为准。旧精简 Demo 仅作视觉参考，不能当成实际能力。

| 蓝图中的操作 | 页面控件/区域 | 实际承接 | 验证 |
| --- | --- | --- | --- |
| 提交多份材料、公开链接或样例 | 上传区、DOI 输入、载入示例 | 文件安全校验、公开候选确认、`POST /api/jobs` | 后端格式/安全测试、浏览器上传 |
| 选择三种策略、可选统计口径 | 检查范围、统计信息核对 | PaperConan 真实扫描 + 确定性补充规则 | 35 行平移 0.3、比例 2；覆盖测试 |
| 看读取范围和线索 | 材料读取情况、摘要、列表 | 标准化结果、工作表/数值/风险与搜索 | 浏览器搜索、筛选与部分读取测试 |
| 看原始证据 | 数据明细 | 原始行列、完整数值、关系式、并排对照 | 证据窗口和舍入样例测试 |
| 可选 AI 解释 | 辅助解释、报价、确认 | `GET/POST /api/explanations`，每条独立账本；发送最小证据 | Mock HTTP + 完整浏览器流程 |
| 人工复核、导出 | 我的复核、生成复核报告、下载 | SQLite 版本冲突保护、四格式冻结报告、初筛 JSON/原始记录 | 复核、报告、下载测试 |
| 重开历史记录 | 筛查记录 | 持久化任务索引与已完成结果 | 重启/浏览器重开测试 |

页面只呈现用户需要的结论、位置和下一步；没有给用户展示模型原始话语、API 密钥、调用日志或后台字段。下载 JSON 和原始记录是核验入口，不是普通用户必须阅读的内容。AI 解释不能改写 PaperConan 结果或人工状态。

验收结论：功能链路在合成样例和 Mock 模型下通过；真实模型仅完成一次最小冒烟，尚无充分证据证明解释质量。20 份近 100 MB 密集数值表未通过容量测试。平台账号、权限和部署不属于此版本实现。
