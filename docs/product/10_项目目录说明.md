# 项目目录说明

仓库根目录是 `Agentic-dev-workflow/`：早期工作流模板保留在 `.agents/`、`.ai-workflow/`，本项目的当前权威入口为根 `README.md` 和 `docs/product/`。上层桌面项目根现在仅保留本仓库、旧 `mvp-demo/`（其虚拟环境仍供本地测试使用）和 `资料归档/`；原始任务书、利德云模板、历史 UI、参考推文及旧运行包已按用途移入 `资料归档/`，不自动上传 GitHub。

| 路径 | 内容 |
| --- | --- |
| `mvp-demo/app.py` | 仅本机的 HTTP API 与任务编排 |
| `mvp-demo/evidence.py`、`statistical_checks.py`、`pattern_checks.py` | 确定性结果标准化和补充规则 |
| `mvp-demo/model_gateway.py`、`finding_explanations.py`、`budget_store.py` | DeepSeek 调用、逐条解释和费用账本 |
| `mvp-demo/review_store.py`、`report_exports.py` | 人工复核与四格式冻结报告 |
| `mvp-demo/static/` | 当前运行页面；`prototypes/` 仅历史参考 |
| `mvp-demo/samples/`、`mvp-demo/tests/` | 合成样例与自动测试 |
| `tools/` | 模型配置、蓝图生成、浏览器/容量/交付验证脚本 |
| `docs/product/` | 当前建设蓝图、教程、验收对照、调研、模型与平台说明 |
| `docs/specs/`、`docs/tasks/` | 历史完整版需求与开发记录，不能替代当前交付声明 |
| `delivery-src/`、`tools/build_delivery.py` | 纳入 Git 的四组件入口与可复现构建源码 |
| `delivery/PaperAudit-20261012042953/` | 最新本机交付包；目录及本地责任范围技术验证通过，平台验收仍待接入，不纳入 Git |

`mvp-demo/runtime/`、`docs/verification/`、`delivery/` 及缓存为本地运行、验收或交付产物，不提交；构建源码则纳入 Git，避免只能依赖本机忽略文件。此前旧交付包和旧 HTML 保存在本地 `docs/archive/`。`docs/references/` 包含第三方参考内容，也不作为可再分发代码上传。原始需求及模板保存在上层桌面的 `资料归档/原始需求与模板/`；完整移动和日报回收站清单见[目录整理清单](11_目录整理清单.md)。规范提示的证据判定与平台排除范围见[本地交付验收](12_佰茵云本地交付验收.md)。
